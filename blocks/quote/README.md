# quote

Custom **quote** block. Purpose: Employee quotation with a circular portrait and attribution.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: portrait image (optional); row 2: quotation; row 3: attribution (name, role).

## Supported variations

No variations.

## Layout

Adjacent Quote blocks in the same section stack below 900px and sit in centered columns from 900px. The section heading stays on its own row above the quotes, including on wide and ultrawide monitors. Portrait sizes and quotation typography are unchanged.
